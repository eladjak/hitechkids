# הייטקידס

דף נחיתה לקייטנת טכנולוגיה לילדים -- בינה מלאכותית, קוד, רובוטיקה וכתיבה יצירתית. כולל ניהול הרשמות דרך Supabase ועיצוב מודרני בעברית.

## תכונות

- דף נחיתה בעברית עם עיצוב צבעוני ומודרני
- הצגת תוכניות: AI, קוד, רובוטיקה, כתיבה יצירתית
- ניהול הרשמות דרך Supabase
- אנימציות חלקות עם Framer Motion
- עיצוב מותאם מובייל

## טכנולוגיות

| טכנולוגיה | שימוש |
|-----------|-------|
| [Next.js 16](https://nextjs.org/) | פריימוורק React |
| [React 19](https://react.dev/) | ספריית UI |
| [TypeScript](https://www.typescriptlang.org/) | בטיחות טיפוסים |
| [Supabase](https://supabase.com/) | בקאנד ומסד נתונים |
| [Tailwind CSS 4](https://tailwindcss.com/) | עיצוב |
| [Framer Motion](https://www.framer.com/motion/) | אנימציות |

## התקנה

```bash
git clone https://github.com/eladjak/hitechkids.git
cd hitechkids
bun install
bun dev
```

פתחו [http://localhost:3000](http://localhost:3000) בדפדפן.
